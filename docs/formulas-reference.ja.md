# 数式の対応範囲・サポート関数

[English](formulas-reference.md) · [使い方・API ガイド](formulas.ja.md) · [README](../README.ja.md)

この資料は、明示的な `Recalculate` モードが使う組込み計算器
`ExcelRenderer.Formulas` の対応範囲です。**下表の40関数**と、上限付きの Excel 数式構文に
対応します。[namespace移行ガイド](namespace-migration.md)も参照してください。
Excel 完全互換を保証するものではありません。既定の `CachedValue` は
数式を評価せず保存結果を表示するため、計算器が未対応の関数でも保存結果を利用できます。

Reader・Core・CLI・Mapping・XLSX 保存の設定例は[使い方ガイド](formulas.ja.md)、
明細展開・マスタ検索・SUMIFS/COUNTIFS・日付・TEXT・描画を組み合わせた実行例は
[請求書サンプル](../samples/ExcelRenderer.Formulas.Sample/README.ja.md)を参照してください。

## 対応する構文と参照

例は先頭に `=` を付けていますが、`FormulaParser.Parse` は `=` なしでも受け付けます。
関数名は英語表記で、大文字・小文字を区別しません。引数区切りはカンマ、小数点は
invariant の `.` です。翻訳された関数名やセミコロン区切りには対応しません。

| 機能 | 例 | 対応範囲 |
| --- | --- | --- |
| 数値 | `=12`、`=-1.25`、`=1.25E-3` | 有限の double。科学表記にも対応します。 |
| 文字列 | `="hello"`、`="a""b"`、`=","` | 二重引用符で囲み、引用符自体は二重にします。文字列中の記号は構文として解釈しません。 |
| 真偽値 | `=TRUE`、`=FALSE`、`=TRUE()` | リテラルと引数0個の関数。 |
| Excel エラー | `=#DIV/0!`、`=#N/A` | 後述の7種類のエラー値。 |
| 括弧・演算子 | `=(A1+2)*3`、`=50%`、`="("&A1&")"` | 単項符号、四則、べき乗、%、文字列連結、比較。 |
| セル参照 | `=A1`、`=$A$1`、`=$A1`、`=A$1` | A1 形式。行は1～1048576、列は A～XFD。`$` はコピー時の移動を制御します。 |
| 別シート | `=Rates!B1`、`='Tax Rates'!B1`、`='O''Brien'!A1` | シート名を単一引用符で囲み、アポストロフィは二重にします。空の引用シート名は不正です。 |
| 矩形範囲 | `=SUM(A1:C10)`、`=SUM(Rates!A1:B3)` | 同一シート上で座標の種類が一致する両端。文字列を範囲端点にはできません。 |
| 全行・全列 | `=SUM(1:10)`、`=SUM(A:C)`、`=SUM($A:$C)` | 組込みDataSourceは疎索引を使い、空白を一括処理します。外部の密DataSourceは訪問上限付きで走査します。 |
| 固定の定義名 | `=SUM(Amounts)`、`=Rates!TaxRate` | 固定セル・矩形範囲。後述の名前解決規則を参照してください。 |
| 引数省略 | `=SUM(,1,)`、`=IF(FALSE,1,)` | 実際に空の引数位置は数値0として扱います。空文字の引数は Text のままです。 |
| 共有数式 | XLSX の共有数式 master／follower | 対応する参照を OpenXml が復元してから計算・Mapping の行参照書換えを行います。文字列は保持します。 |

XLSX の定義名は `Rates!$B$1` や `Invoice!$D$2:$D$10` のように、シート名と完全絶対参照を
持つ単一セル・矩形範囲に対応します。シート名なしの名前解決では、シートローカル定義を
ブック全体の定義より優先します。シート名付きの名前は、そのシートのローカル定義を解決します。
式・相対参照・複数領域を表す定義名は未対応です。単独エンジンの Builder では、名前を
固定の `FormulaRange` に直接割り当てます。

範囲は配列値ではなく参照です。集計へ範囲を渡したり、IF で範囲を選んで外側の集計へ渡す
`=SUM(IF(TRUE,A1:A3,B1:B3))` は使えます。`=A1:A3` のように複数セル範囲を単一値として
返すと `UnsupportedArrayEvaluation` になり、左上のセルを暗黙に選びません。

## 演算子と優先順位

表は優先順位の高い順です。本計算器の明示的な互換プロファイルであり、特に
`=-2^2` → **4**、`=2^3^2` → **64** となる点を、既存の式を使う際に確認してください。

| 優先順位 | 演算子 | 動作 |
| --- | --- | --- |
| 1 | 単項 `+`、`-` | べき乗より先に結合します。 |
| 2 | 後置 `%` | 100で割ります。 |
| 3 | `^` | べき乗。左結合です。 |
| 4 | `*`、`/` | 乗算・除算。 |
| 5 | 二項 `+`、`-` | 加算・減算。 |
| 6 | `&` | 文字列連結。数値は invariant G15、真偽値は TRUE/FALSE で文字列化します。 |
| 7 | `=`、`<>`、`<`、`<=`、`>`、`>=` | 比較。文字列は OrdinalIgnoreCase、空白以外の異型は Number < Text < Boolean の順序です。 |

括弧で結合順を指定できます。非有限の計算結果は `#NUM!` です。このプロファイルでは
`=0^0` は `#NUM!`、`=0^-1` は `#DIV/0!` になります。

## サポート関数一覧

引数数は構文上の引数数で、範囲内のセル数ではありません。範囲には多数のセルを含められますが、
セッションの資源上限を適用します。対応する名前は以下のみです。関数呼出しを構文解析できても、
その関数を評価できるとは限りません。

範囲を使う例は、`Examples`シートの次のデータで評価します。日付の数値結果は1900日付系です。

| Row | A | B | C |
| --- | --- | ---: | --- |
| 1 | Office | 10 | TRUE |
| 2 | Travel | 20 | TRUE |
| 3 | Office | 30 | FALSE |
| 4 | Office | 40 | TRUE |

| 関数 | 引数数 | 動作 | 例と結果 |
| --- | --- | --- | --- |
| `SUM` | 0～255 | 数値の合計。数値がなければ0。 | `=SUM(2,3)` → 5 |
| `COUNT` | 0～255 | 数値を数え、直接引数の変換可能値も数えます。通常の Excel エラーは無視します。 | `=COUNT(1,"2",TRUE)` → 3 |
| `COUNTA` | 0～255 | 空白以外を数えます。空の Text、真偽値、Excel エラーも含みます。 | `=COUNTA("","x")` → 2 |
| `MIN` | 1～255 | 数値の最小値。数値がなければ0。 | `=MIN(5,2)` → 2 |
| `MAX` | 1～255 | 数値の最大値。数値がなければ0。 | `=MAX(5,2)` → 5 |
| `AVERAGE` | 1～255 | 数値の算術平均。数値がなければ `#DIV/0!`。 | `=AVERAGE(2,4)` → 3 |
| `IF` | 2～3 | 選択した値の分岐だけを評価します。第3引数がなく条件が偽なら FALSE。 | `=IF(TRUE,"ok","no")` → "ok" |
| `IFERROR` | 2 | 通常の Excel エラー値の場合だけ代替値を評価します。第1引数は単一値が必要です。 | `=IFERROR(1/0,0)` → 0 |
| `AND` | 1～255 | 論理積。後続のエラーも評価します。有効な論理入力がなければ `#VALUE!`。 | `=AND(TRUE,FALSE)` → FALSE |
| `OR` | 1～255 | 論理和。後続のエラーも評価します。有効な論理入力がなければ `#VALUE!`。 | `=OR(TRUE,FALSE)` → TRUE |
| `NOT` | 1 | 論理変換した値の否定。 | `=NOT(TRUE)` → FALSE |
| `ROUND` | 2 | num_digits の小数桁へ丸めます。中間値は0から遠い方。 | `=ROUND(1.005,2)` → 1.01 |
| `ROUNDUP` | 2 | 捨てる十進桁が非ゼロなら0から遠い方へ丸めます。 | `=ROUNDUP(-1.21,1)` → -1.3 |
| `ROUNDDOWN` | 2 | 0方向へ丸めます。 | `=ROUNDDOWN(0.29,2)` → 0.29 |
| `ABS` | 1 | 絶対値。 | `=ABS(-3)` → 3 |
| `INT` | 1 | 負の無限大方向へ切り捨てます。 | `=INT(-1.2)` → -2 |
| `MOD` | 2 | `number - divisor * floor(number / divisor)`。除数0は `#DIV/0!`。 | `=MOD(-3,2)` → 1 |
| `TRUE` | 0 | 真の Boolean。 | `=TRUE()` → TRUE |
| `FALSE` | 0 | 偽の Boolean。 | `=FALSE()` → FALSE |
| `SUMIF` | 2～3 | 単一条件。sum_rangeは左上を基点に寸法を補正します。 | `=SUMIF(A1:A4,"Office",B1:B4)` → 80 |
| `SUMIFS` | 3～255、奇数 | 同寸法の範囲で全条件に一致した数値を合計。1～127組。 | `=SUMIFS(B1:B4,A1:A4,"Office",C1:C4,TRUE)` → 50 |

| `LEFT` | 1～2 | UTF-16単位の先頭部分。既定の長さは1。 | `=LEFT("Invoice",3)` → "Inv" |
| `RIGHT` | 1～2 | UTF-16単位の末尾部分。既定の長さは1。 | `=RIGHT("Invoice",4)` → "oice" |

| `LEN` | 1 | 書記素ではなくUTF-16コード単位の数。 | `=LEN("😀")` → 2 |

### 条件付き集計

```text
SUMIF(range, criteria, [sum_range])
SUMIFS(sum_range, criteria_range1, criteria1, [...])
COUNTIF(range, criteria)
COUNTIFS(criteria_range1, criteria1, [...])
```

SUMIFS・COUNTIFSは範囲と条件を1～127組指定します。全範囲の行数・列数が同じでなければ
`#VALUE!`です。範囲の開始位置やシートが違っても、相対位置が同じセル同士を照合します。
SUMIFのsum_rangeは左上を基点としてrangeの寸法に補正します。上のデータなら
`=SUMIF(A1:A4,"Office",B1)`も80です。補正後の範囲がXFD／1048576行を超えると`#REF!`です。
sum_range省略時はrange自体を合計します。合計対象では数値だけを加算し、一致した合計セルの
Excelエラーは伝播します。

条件は単一値、または`=`・`<>`・`<`・`<=`・`>`・`>=`を先頭に付けた文字列です。
`">="&B1`のように演算子とセル値を連結できます。文字列比較はOrdinalIgnoreCaseです。
この明示的プロファイルでは、数値条件は変換可能な数値文字列にも一致し、欠落Blankを0と
扱います。真偽値条件は型付きのBooleanに一致します。`""`は欠落Blankと空のTextに一致しますが、
保存された値として両者は区別します。`=COUNTIF(A:A,"")`は使用範囲だけでなく1048576行全体の
空白位置を数えます。数式の結果が0・空文字・FALSE・Excelエラーでも欠落させません。

文字列の等値・不等値条件では、`*`は任意の長さ、`?`はUTF-16の1単位、`~`はワイルドカードの
エスケープです。`"~*"`はアスタリスク自体に一致します。ワイルドカードの等値条件は空のTextを
含むTextに一致しますが、欠落Blankには一致しません。条件に直接渡したExcelエラーは伝播します。
`"#N/A"`のようにエラー名をTextとして渡すと、保存されたエラー値を選択できます。
これらは[Oracleの仕様プロファイル](formulas-oracle.md)であり、Excel実機での互換性認証ではありません。

### 完全一致検索と単一セルのINDEX

```text
VLOOKUP(lookup_value, table_array, col_index_num, FALSE)
MATCH(lookup_value, lookup_array, 0)
INDEX(reference, row_num, [column_num])
```

引数数の一覧では一般的な構文と同様にモード省略を受け付けますが、評価時には
**VLOOKUPのFALSE/0、MATCHの0を明示する必要があります**。省略や近似検索の指定は
`UnsupportedFeature`となり、IFERRORでも隠せません。したがって
`=VLOOKUP("Travel",A1:B4,2)`は未対応で、`FALSE`を加えた式は20です。

VLOOKUPは表の先頭列を検索して同じ行の指定列を返します。MATCHは縦または横のベクトルを
検索し、1始まりの位置を返します。重複時は最初の一致を採用し、大文字・小文字を区別せず、
上記の文字列ワイルドカードにも対応します。型は維持し、Textの`"10"`とNumberの10は
一致しません。欠落した検索キーは0となり、数値0のキーは空白位置に一致します。
不一致は`#N/A`です。一致より前に到達した検索セルのエラーは伝播し、後続行や未選択の戻り列を
検索のためだけに評価しません。VLOOKUPの小数の列番号は0方向へ切り捨て、1未満は`#VALUE!`、
表の列数を超えると`#REF!`です。

INDEXは**単一セルへの参照**を返すため、`=SUM(INDEX(B1:B4,3))`も30です。
2次元範囲には行番号と列番号の両方が必要です。1列なら`INDEX(B1:B4,3)`、1行なら
`INDEX(B1:D1,2)`で指定できます。`INDEX(B1:D1,,2)`や`INDEX(B1:B4,3,)`も対応する添字を
省略できます。小数の添字は0方向へ切り捨て、負数は`#VALUE!`、範囲外は`#REF!`です。
0の添字・配列・複数領域・列番号を省略した2次元範囲は、未対応の配列操作として
`UnsupportedArrayEvaluation`になります。area_numを受け付ける形式はありません。

### 日付とブックの日付系

```text
DATE(year, month, day)
YEAR(serial_number) / MONTH(serial_number) / DAY(serial_number)
EDATE(start_date, months) / EOMONTH(start_date, months)
```

日付は数値シリアルであり、カルチャ依存の文字列を日付解析しません。単独セッションでは
`FormulaEvaluationOptions.DateSystem`（既定`Excel1900`）を使い、OpenXmlではブックの
`Date1904`フラグを使います。オプションはコピーし、呼出元のオブジェクトを書き換えません。
1904日付系のシリアル0は1904-01-01です。1900日付系ではシリアル0を1900/1/0、シリアル60を
架空の1900-02-29として保持するため、`=DAY(60)`は29です。負数・範囲外は`#NUM!`となり、
最大日付は9999-12-31です。

DATEは数値引数を0方向へ切り捨て、入力年0～1899には1900を加え、月・日のはみ出しを
正規化します。`=DATE(2026,2,0)`と`=DATE(2026,1,31)`は同じ値（1900日付系では46053）です。
YEAR/MONTH/DAYは時刻の小数部分を切り捨てます。EDATE/EOMONTHは月の移動数を0方向へ
切り捨て、時刻部分を落とし、必要に応じて日を移動先の月末へ制限します。
`=TEXT(EDATE(DATE(2026,1,31),1),"yyyy-mm-dd")`は`"2026-02-28"`です。

XLSXのISO日付セルはタイムゾーンのないISO日付・日時を受け付け、シリアル化時に時刻の
小数部分を保持します。地域依存の日付文字列やタイムゾーン付きISO値は未対応です。
日付関数内部で地域依存の文字列日付パーサーを呼びません。

### 文字列関数とTEXTの対応書式

```text
LEFT(text, [num_chars]) / RIGHT(text, [num_chars])
MID(text, start_num, num_chars) / LEN(text) / TRIM(text)
SUBSTITUTE(text, old_text, new_text, [instance_num])
CONCATENATE(text1, [...]) / TEXT(value, format_text)
```

LEFT/RIGHTの既定の長さは1です。長さは非負、位置は1始まりで、小数は0方向へ切り捨てます。
負の長さや1未満のMID開始位置は`#VALUE!`、文字列末尾より後の開始位置は空のTextです。
位置・長さはいずれもUTF-16コード単位です。`=LEN("😀")`は2で、部分切出しはサロゲートペアを
分割する場合があります。書記素単位の切出しではありません。TRIMはASCII U+0020だけの前後と
連続空白を整理し、タブ・U+00A0・全角空白は保持します。

SUBSTITUTEは大文字・小文字を区別し、重複しない箇所を置換します。instance_num省略時はすべて、
正の1始まりの回数を指定するとその箇所だけを置換します。切捨て後の回数が0以下なら`#VALUE!`です。
old_textが空なら入力を保持します。CONCATENATEは1～255個の単一値を連結し、数値をinvariant G15、
真偽値をTRUE/FALSEに変換します。複数セル範囲の展開は行いません。

TEXTは次のinvariant書式に対応し、結果はすべてTextです。

| 書式 | 例 | 結果 |
| --- | --- | --- |
| 0埋め | `=TEXT(42,"00000")` | `"00042"` |
| 必須の小数桁 | `=TEXT(12.5,"0.00")` | `"12.50"` |
| 桁区切り | `=TEXT(1234.5,"#,##0.00")` | `"1,234.50"` |
| パーセント | `=TEXT(0.125,"0.0%")` | `"12.5%"` |
| 年月日 | `=TEXT(DATE(2026,1,31),"yyyy-mm-dd")` | `"2026-01-31"` |
| 年月 | `=TEXT(DATE(2026,1,31),"yyyy年mm月")` | `"2026年01月"` |

数値部分は1個以上の`0`または`#,##0`に、必須の小数0と末尾の`%`を任意で加えられます。
引用符付きの前後リテラルにも対応します。日付トークンは年→月→日、または年→月の順で、
`yyyy`・`m`/`mm`・`d`/`dd`と、`-`・`/`・`年`・`月`・`日`などの区切りを使います。
英字トークンの大小は区別しません。地域設定に関係なく小数点は`.`、桁区切りは`,`です。
数値書式には後述の十進丸めプロファイルを使います。

時刻・曜日・月名・ロケール／元号コード・色・条件／複数セクション・科学表記・分数・会計書式は
`UnsupportedFeature`です。TEXTは上限付きの部分対応であり、Excelの書式言語全体ではありません。
TEXTは整形結果の長さを割当前に検査し、評価結果と保持文字列は後述する2種類のText資源上限に従います。

### 型変換と評価

- 数値演算・関数は、ASCII のスペース・タブ・改行を除いた invariant の符号付き小数・指数の
  Text を数値化します。通貨、桁区切り、%付き文字列、日付文字列は数値化しません。
  真偽値は1／0、空白セルは数値の文脈で0へ変換します。
- SUM／MIN／MAX／AVERAGE は参照経由の Text・真偽値・空白を無視します。
  直接渡した数値 Text・真偽値は変換し、不正な数値 Text は `#VALUE!`。
  Excel エラーは伝播します。COUNT は通常の Excel エラーを無視し、COUNTA は数えます。
  空の Text と空白セルは区別します。
- 論理変換は真偽値、数値（0は偽）、空白（偽）、大文字・小文字を区別しない TRUE/FALSE の
  Text を受け付けます。AND／OR は参照経由の Text・空白を無視しますが、後続エラーを短絡で消しません。
- IF／IFERROR は選択した値の分岐だけを評価しますが、到達した数式の AST 全体で関数名と
  引数数を事前検査します。`=IF(TRUE,1,UNKNOWN())` は `UnsupportedFunction`。
  未選択分岐のセル参照は、その分岐を評価するためだけには読みません。

### 十進丸めのプロファイル

Number は double のままです。ROUND／ROUNDUP／ROUNDDOWN の桁処理だけで、入力 double の
invariant 最短ラウンドトリップ十進表現を整数係数・指数へ分解し、整数の商・余りで丸めて
再び double に戻します。num_digits は0方向に整数化し、正なら小数部、負なら十・百などの
桁を扱います。例えば `=ROUND(125,-1)` は130、`=ROUND(-2.5,0)` は-3です。

`ROUND(1.005,2)` などの二進桁移動の誤差を防ぎ、隣接する double の違いは維持します。
計算で生じた 0.30000000000000004 を0.3へ正規化したり、Excel 内部のすべての精度補正を
再現する方式ではありません。非有限の結果は `#NUM!`。非ゼロ入力で桁数が -308 未満なら
正の0にする挙動を含め、既存の0の符号を維持します。
[互換プロファイル](formulas.ja.md#限定互換プロファイル)と
[正しさ・性能の検証記録](formulas-review-fixes-validation.md)も参照してください。

## 計算エラーとエンジン診断

通常の Excel エラーは型付きの値で、`#NULL!`、`#DIV/0!`、`#VALUE!`、`#REF!`、`#NAME?`、
`#NUM!`、`#N/A` の7種類です。単独エンジンの評価が成功して Error 値を返す場合があり、
XLSX にはエラー型のキャッシュで保存します。IFERROR はこれらを捕捉できます。
例えば未解決の名前は `#NAME?` ですが、未対応関数はエンジンの失敗です。

| エンジンの失敗 | 主な原因 |
| --- | --- |
| `SyntaxError`、`UnsupportedSyntax`、`InvalidReference` | 不正な構文、未対応の参照文法、座標上限外のセル。 |
| `UnsupportedFeature` | 近似検索モード、未対応のTEXT書式。 |
| `UnsupportedFunction` | 40関数以外の呼出し。 |
| `InvalidArgumentCount` | 対応関数へ不正な数の引数を渡す。 |
| `UnsupportedArrayEvaluation` | 単一値が必要な場所で複数セル範囲を使う。 |
| `CircularReference` | 到達した依存セルの循環。依存経路を診断に含めます。 |
| `ResourceLimitExceeded` | 構文解析・評価・Text 一値・保持 Text 合計の上限超過。 |
| `DataSourceFailure` | データの読取・解決の失敗。 |

単独 API は `Success=false` と `Diagnostics` で失敗を返し、OpenXml 統合は
`FormulaCalculationException` を送出します。公開描画 API ではこの例外をラップする場合が
あります。IFERROR はエンジンの失敗を隠しません。取消しは `OperationCanceledException` です。
到達した未対応式を古い保存結果で補いません。最終コピー前の再計算失敗は出力先を変更しませんが、
最終的な出力先への書込失敗は部分的な出力が残る場合があります。

## 資源制限

`FormulaEvaluationOptions` の既定値は以下です。生成時に設定をセッションへコピーするため、
入力や上限を変更した場合は新しいセッションを作ります。計算結果の再利用は一つの不変入力を
扱うセッション内だけで行い、グローバルな結果キャッシュは使いません。

| 設定 | 既定値 | 単位・範囲 |
| --- | ---: | --- |
| `MaxFormulaLength` | 8192 | 数式ごとの UTF-16 コード単位 |
| `MaxAstNodes` | 16384 | 数式ごとの AST ノード数 |
| `MaxSyntaxDepth` | 128 | パーサー・AST の深さ |
| `MaxDependencyDepth` | 256 | 同時に辿るセル依存の深さ |
| `MaxFormulaCells` | 100000 | セッションごとに評価する数式セル数 |
| `MaxCellVisits` | 1000000 | セッションごとのセル読取・範囲訪問回数 |
| `MaxEvaluationSteps` | 2000000 | セッションごとの検証・評価ステップ |
| `MaxStringLength` | 32767 | 一時的な連結を含む、評価する Text 一値の UTF-16 長 |
| `MaxCachedStringCharacters` | 16777216 | 異なるキャッシュセルが保持する Text の UTF-16 長の合計 |

Text の二つの上限は0を許可し、それぞれ空の評価 Text／保持 Text だけを許可します。
負数はセッション生成時に拒否します。surrogate pair は UTF-16 で2単位です。同一セルの再読取や
同じ結果の results 辞書登録は二重計上せず、同じ文字列でも異なるセルなら各セル分を数えます。
保持しない `Evaluate(parsed)` の返却値は累積予算に含めず、連結は結果の確保前に合計長を検査します。
Text の上限診断には数式セル・元の Span・超過した上限名を含め、全文字列は含めません。
呼出し元のデータ・OpenXml スナップショット・プロセス全体のメモリはこの予算の対象外です。
Excel のすべての Unicode 長さ規則との互換保証でもありません。
設定例と保持量の詳細は[使い方ガイド](formulas.ja.md#文字列の資源制限)を参照してください。

## 未対応の機能

| 分類 | 例 |
| --- | --- |
| 一覧以外の関数 | XLOOKUP、CONCAT、TODAY／NOW、財務関数など、表の40関数にないすべての名前。 |
| 配列計算 | 配列定数、旧式配列数式、動的配列・スピル、配列を返す評価。到達した XLSX data table 数式・計算メタデータも拒否します。 |
| 参照文法 | 外部ブック、3D、構造化・テーブル参照、R1C1、暗黙の交差 `@`、スピル `#`、参照の和集合・交差。 |
| 名前・実行 | 式・相対・複数領域の定義名、INDIRECT／OFFSET、LET／LAMBDA、揮発性の実行、UDF／VBA、反復・循環計算。 |
| ロケール・日付 | 翻訳された数式構文、ロケール依存の文字比較、ロケール依存の日付文字列・タイムゾーン付きISO日付セルの変換。日付関数はセッション／ブックの日付系に従って数値シリアルを解釈します。 |

CachedValue 描画での定数文字列 HYPERLINK のリンク情報抽出は別機能であり、HYPERLINK は
計算器の対応関数ではありません。本体は[第1・第2段階の条件付き書式](conditional-formatting.md)の
条件式とカラースケール閾値の式を同じエンジンで評価します。母集団の集計・順位・色補間は
本体の責務です。Core は通常の保存書式を使い、入力規則の数式はメタデータの
ままです。対応関数であっても、到達する依存先が未対応の機能を使ったり、資源上限を
超えたりすると失敗します。

この一覧は実装済みの範囲で、Excel 実機との互換性認証ではありません。検証対象 SHA と
未実施の範囲は[統合検証](formulas-validation.md)、[レビュー修正の検証](formulas-review-fixes-validation.md)、
[性能](formulas-performance.md)に記録しています。

## 疎範囲と検索の性能契約

組込みDataSourceは`ISparseFormulaDataSource`を実装します。外部の`IFormulaDataSource`は
既存のまま上限付きの密走査を使えます。疎契約では、数式の0・空文字・エラーや計算メタデータを
含む全保存座標を、重複のない行優先順で列挙します。欠落セルを結果キャッシュに保持しません。
条件範囲は相対位置のカーソルをマージし、全列分の配列を割り当てません。

`FormulaSession.GetStatistics()`は実読込数・候補数・一括処理した空白位置数・セル訪問数・
ステップ数・保持数を返します。密範囲への直接走査は座標索引から全座標の保存を証明できる場合だけ
選択し、UsedRangeなどの外形だけで判定しません。外部カーソルの順序と重複も検査します。

単一列は「列→昇順行番号」の座標索引を使い、存在しない列は即座に空列挙を返します。
対象列の保存セル数をNcol、返却座標数をKとするとO(log Ncol + K)で、別列の行数には比例しません。
複数列は既存の行優先索引を使います。追加の保持メモリは保存セル数に比例する座標索引で、
セル値や評価結果を複製しません。

追加統計`IndexWork`は、組込み索引の辞書検索・二分探索の比較・調べた行や座標を数え、
密範囲の証明処理も含みます。各単位で評価ステップを1消費し、キャンセルを確認するため、
候補を返さない`MoveNext`内部の走査にも上限が適用されます。バッチ化による遅延はありません。
既存の`SourceReads`と`RangeCandidates`の意味は維持します。この保証は組込みの
`FormulaRangeIndex.Query`に対するもので、任意の外部列挙子の`MoveNext`内部を強制中断するものではありません。

完全一致検索は、評価したベクトルの先頭部分だけをセッション内索引に保持します。
重複時の最初の一致・型付き比較・エラー順序・遅延評価を維持し、繰返し検索で先頭からの
走査を省きます。上限は1セッションにつき16ベクトル・65536型付き値・131072文字単位で、
到達後は資源上限付きのストリーミングへ戻ります。呼出しを跨いでカーソルを保持せず、
ワイルドカードの索引検索も同じステップ上限に従います。

[数式拡張の検証](formulas-expansion-validation.md)と[Oracleの出典](formulas-oracle.md)は、
仕様比較の結果と未実施のExcel実機比較を区別しています。
