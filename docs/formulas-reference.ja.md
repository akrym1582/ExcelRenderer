# 数式の対応範囲・サポート関数

[English](formulas-reference.md) · [使い方・API ガイド](formulas.ja.md) · [README](../README.ja.md)

この資料は、明示的な `Recalculate` モードが使う組込み計算器
`ExcelRenderer.Formulas` の対応範囲です。**下表の40関数**と、上限付きの Excel 数式構文に
対応します。Excel 完全互換を保証するものではありません。既定の `CachedValue` は
数式を評価せず保存結果を表示するため、計算器が未対応の関数でも保存結果を利用できます。

Reader・Core・CLI・Mapping・XLSX 保存の設定例は[使い方ガイド](formulas.ja.md)、
明細展開・別シート税率・ROUND・SUM・描画を組み合わせた実行例は
[請求書サンプル](../samples/ExcelRenderer.Formulas.Sample/README.ja.md)を参照してください。

## 対応する構文と参照

例は先頭に `=` を付けていますが、`FormulaParser.Parse` は `=` なしでも受け付けます。
関数名は英語表記で、大文字・小文字を区別しません。引数区切りはカンマ、小数点は
invariant の `.` です。翻訳された関数名やセミコロン区切りには対応しません。

| 機能 | 例 | 対応範囲 |
| --- | --- | --- |
| 数値 | `=12`、`=-1.25`、`=1.25E-3` | 有限の double。科学表記にも対応します。 |
| 文字列 | `="hello"`、`="a""b"`、`=","` | 二重引用符で囲み、引用符自体は二重にします。文字列中の記号は構文として解釈しません。 |
| 真偽値 | `=TRUE`、`=FALSE`、`=TRUE()` | リテラルと引数0個の関数。 |
| Excel エラー | `=#DIV/0!`、`=#N/A` | 後述の7種類のエラー値。 |
| 括弧・演算子 | `=(A1+2)*3`、`=50%`、`="("&A1&")"` | 単項符号、四則、べき乗、%、文字列連結、比較。 |
| セル参照 | `=A1`、`=$A$1`、`=$A1`、`=A$1` | A1 形式。行は1～1048576、列は A～XFD。`$` はコピー時の移動を制御します。 |
| 別シート | `=Rates!B1`、`='Tax Rates'!B1`、`='O''Brien'!A1` | シート名を単一引用符で囲み、アポストロフィは二重にします。空の引用シート名は不正です。 |
| 矩形範囲 | `=SUM(A1:C10)`、`=SUM(Rates!A1:B3)` | 同一シート上で座標の種類が一致する両端。文字列を範囲端点にはできません。 |
| 全行・全列 | `=SUM(1:10)`、`=SUM(A:C)`、`=SUM($A:$C)` | 組込みDataSourceは疎索引を使い、空白を一括処理します。外部の密DataSourceは訪問上限付きで走査します。 |
| 固定の定義名 | `=SUM(Amounts)`、`=Rates!TaxRate` | 固定セル・矩形範囲。後述の名前解決規則を参照してください。 |
| 引数省略 | `=SUM(,1,)`、`=IF(FALSE,1,)` | 実際に空の引数位置は数値0として扱います。空文字の引数は Text のままです。 |
| 共有数式 | XLSX の共有数式 master／follower | 対応する参照を OpenXml が復元してから計算・Mapping の行参照書換えを行います。文字列は保持します。 |

XLSX の定義名は `Rates!$B$1` や `Invoice!$D$2:$D$10` のように、シート名と完全絶対参照を
持つ単一セル・矩形範囲に対応します。シート名なしの名前解決では、シートローカル定義を
ブック全体の定義より優先します。シート名付きの名前は、そのシートのローカル定義を解決します。
式・相対参照・複数領域を表す定義名は未対応です。単独エンジンの Builder では、名前を
固定の `FormulaRange` に直接割り当てます。

範囲は配列値ではなく参照です。集計へ範囲を渡したり、IF で範囲を選んで外側の集計へ渡す
`=SUM(IF(TRUE,A1:A3,B1:B3))` は使えます。`=A1:A3` のように複数セル範囲を単一値として
返すと `UnsupportedArrayEvaluation` になり、左上のセルを暗黙に選びません。

## 演算子と優先順位

表は優先順位の高い順です。本計算器の明示的な互換プロファイルであり、特に
`=-2^2` → **4**、`=2^3^2` → **64** となる点を、既存の式を使う際に確認してください。

| 優先順位 | 演算子 | 動作 |
| --- | --- | --- |
| 1 | 単項 `+`、`-` | べき乗より先に結合します。 |
| 2 | 後置 `%` | 100で割ります。 |
| 3 | `^` | べき乗。左結合です。 |
| 4 | `*`、`/` | 乗算・除算。 |
| 5 | 二項 `+`、`-` | 加算・減算。 |
| 6 | `&` | 文字列連結。数値は invariant G15、真偽値は TRUE/FALSE で文字列化します。 |
| 7 | `=`、`<>`、`<`、`<=`、`>`、`>=` | 比較。文字列は OrdinalIgnoreCase、空白以外の異型は Number < Text < Boolean の順序です。 |

括弧で結合順を指定できます。非有限の計算結果は `#NUM!` です。このプロファイルでは
`=0^0` は `#NUM!`、`=0^-1` は `#DIV/0!` になります。

## サポート関数一覧

引数数は構文上の引数数で、範囲内のセル数ではありません。範囲には多数のセルを含められますが、
セッションの資源上限を適用します。対応する名前は以下のみです。関数呼出しを構文解析できても、
その関数を評価できるとは限りません。

| 関数 | 引数数 | 動作 | 例と結果 |
| --- | --- | --- | --- |
| `SUM` | 0～255 | 数値の合計。数値がなければ0。 | `=SUM(2,3)` → 5 |
| `COUNT` | 0～255 | 数値を数え、直接引数の変換可能値も数えます。通常の Excel エラーは無視します。 | `=COUNT(1,"2",TRUE)` → 3 |
| `COUNTA` | 0～255 | 空白以外を数えます。空の Text、真偽値、Excel エラーも含みます。 | `=COUNTA("","x")` → 2 |
| `MIN` | 1～255 | 数値の最小値。数値がなければ0。 | `=MIN(5,2)` → 2 |
| `MAX` | 1～255 | 数値の最大値。数値がなければ0。 | `=MAX(5,2)` → 5 |
| `AVERAGE` | 1～255 | 数値の算術平均。数値がなければ `#DIV/0!`。 | `=AVERAGE(2,4)` → 3 |
| `IF` | 2～3 | 選択した値の分岐だけを評価します。第3引数がなく条件が偽なら FALSE。 | `=IF(TRUE,"ok","no")` → Text("ok") |
| `IFERROR` | 2 | 通常の Excel エラー値の場合だけ代替値を評価します。第1引数は単一値が必要です。 | `=IFERROR(1/0,0)` → 0 |
| `AND` | 1～255 | 論理積。後続のエラーも評価します。有効な論理入力がなければ `#VALUE!`。 | `=AND(TRUE,FALSE)` → FALSE |
| `OR` | 1～255 | 論理和。後続のエラーも評価します。有効な論理入力がなければ `#VALUE!`。 | `=OR(TRUE,FALSE)` → TRUE |
| `NOT` | 1 | 論理変換した値の否定。 | `=NOT(TRUE)` → FALSE |
| `ROUND` | 2 | num_digits の小数桁へ丸めます。中間値は0から遠い方。 | `=ROUND(1.005,2)` → 1.01 |
| `ROUNDUP` | 2 | 捨てる十進桁が非ゼロなら0から遠い方へ丸めます。 | `=ROUNDUP(-1.21,1)` → -1.3 |
| `ROUNDDOWN` | 2 | 0方向へ丸めます。 | `=ROUNDDOWN(0.29,2)` → 0.29 |
| `ABS` | 1 | 絶対値。 | `=ABS(-3)` → 3 |
| `INT` | 1 | 負の無限大方向へ切り捨てます。 | `=INT(-1.2)` → -2 |
| `MOD` | 2 | `number - divisor * floor(number / divisor)`。除数0は `#DIV/0!`。 | `=MOD(-3,2)` → 1 |
| `TRUE` | 0 | 真の Boolean。 | `=TRUE()` → TRUE |
| `FALSE` | 0 | 偽の Boolean。 | `=FALSE()` → FALSE |
| `SUMIF` | 2–3 | 単一条件。sum_rangeを左上基点で寸法補正。 | `=SUMIF(...)` |
| `SUMIFS` | 3–255, pairs | 同寸法の範囲を相対位置で照合して合計。 | `=SUMIFS(...)` |
| `COUNTIF` | 2 | 単一条件の一致数。欠落Blankも一括計数。 | `=COUNTIF(...)` |
| `COUNTIFS` | 2–254, pairs | 1～127組。同寸法の全条件一致数。 | `=COUNTIFS(...)` |
| `VLOOKUP` | 3–4 | FALSE/0の完全一致のみ。最初の一致行。 | `=VLOOKUP(...)` |
| `MATCH` | 2–3 | 0の完全一致のみ。縦横ベクトルの1始まり位置。 | `=MATCH(...)` |
| `INDEX` | 2–3 | 単一セル参照を保持。1次元の適切な添字省略可。 | `=INDEX(...)` |
| `DATE` | 3 | 日付系に従い年月日のはみ出しを正規化。 | `=DATE(...)` |
| `YEAR / MONTH / DAY` | 1 each | 暦成分。serial 60を1900-02-29として保持。 | `=YEAR(...)` |
| `EDATE` | 2 | 月を移動し、日を移動先月末までに制限。 | `=EDATE(...)` |
| `EOMONTH` | 2 | 移動先の月末。 | `=EOMONTH(...)` |

### 型変換と評価

- 数値演算・関数は、ASCII のスペース・タブ・改行を除いた invariant の符号付き小数・指数の
  Text を数値化します。通貨、桁区切り、%付き文字列、日付文字列は数値化しません。
  真偽値は1／0、空白セルは数値の文脈で0へ変換します。
- SUM／MIN／MAX／AVERAGE は参照経由の Text・真偽値・空白を無視します。
  直接渡した数値 Text・真偽値は変換し、不正な数値 Text は `#VALUE!`。
  Excel エラーは伝播します。COUNT は通常の Excel エラーを無視し、COUNTA は数えます。
  空の Text と空白セルは区別します。
- 論理変換は真偽値、数値（0は偽）、空白（偽）、大文字・小文字を区別しない TRUE/FALSE の
  Text を受け付けます。AND／OR は参照経由の Text・空白を無視しますが、後続エラーを短絡で消しません。
- IF／IFERROR は選択した値の分岐だけを評価しますが、到達した数式の AST 全体で関数名と
  引数数を事前検査します。`=IF(TRUE,1,UNKNOWN())` は `UnsupportedFunction`。
  未選択分岐のセル参照は、その分岐を評価するためだけには読みません。

### 十進丸めのプロファイル

Number は double のままです。ROUND／ROUNDUP／ROUNDDOWN の桁処理だけで、入力 double の
invariant 最短ラウンドトリップ十進表現を整数係数・指数へ分解し、整数の商・余りで丸めて
再び double に戻します。num_digits は0方向に整数化し、正なら小数部、負なら十・百などの
桁を扱います。例えば `=ROUND(125,-1)` は130、`=ROUND(-2.5,0)` は-3です。

`ROUND(1.005,2)` などの二進桁移動の誤差を防ぎ、隣接する double の違いは維持します。
計算で生じた 0.30000000000000004 を0.3へ正規化したり、Excel 内部のすべての精度補正を
再現する方式ではありません。非有限の結果は `#NUM!`。非ゼロ入力で桁数が -308 未満なら
正の0にする挙動を含め、既存の0の符号を維持します。
[互換プロファイル](formulas.ja.md#限定互換プロファイル)と
[正しさ・性能の検証記録](formulas-review-fixes-validation.md)も参照してください。

## 計算エラーとエンジン診断

通常の Excel エラーは型付きの値で、`#NULL!`、`#DIV/0!`、`#VALUE!`、`#REF!`、`#NAME?`、
`#NUM!`、`#N/A` の7種類です。単独エンジンの評価が成功して Error 値を返す場合があり、
XLSX にはエラー型のキャッシュで保存します。IFERROR はこれらを捕捉できます。
例えば未解決の名前は `#NAME?` ですが、未対応関数はエンジンの失敗です。

| エンジンの失敗 | 主な原因 |
| --- | --- |
| `SyntaxError`、`UnsupportedSyntax`、`InvalidReference` | 不正な構文、未対応の参照文法、座標上限外のセル。 |
| `UnsupportedFunction` | 40関数以外の呼出し。 |
| `InvalidArgumentCount` | 対応関数へ不正な数の引数を渡す。 |
| `UnsupportedArrayEvaluation` | 単一値が必要な場所で複数セル範囲を使う。 |
| `CircularReference` | 到達した依存セルの循環。依存経路を診断に含めます。 |
| `ResourceLimitExceeded` | 構文解析・評価・Text 一値・保持 Text 合計の上限超過。 |
| `DataSourceFailure` | データの読取・解決の失敗。 |

単独 API は `Success=false` と `Diagnostics` で失敗を返し、OpenXml 統合は
`FormulaCalculationException` を送出します。公開描画 API ではこの例外をラップする場合が
あります。IFERROR はエンジンの失敗を隠しません。取消しは `OperationCanceledException` です。
到達した未対応式を古い保存結果で補いません。最終コピー前の再計算失敗は出力先を変更しませんが、
最終的な出力先への書込失敗は部分的な出力が残る場合があります。

## 資源制限

`FormulaEvaluationOptions` の既定値は以下です。生成時に設定をセッションへコピーするため、
入力や上限を変更した場合は新しいセッションを作ります。計算結果の再利用は一つの不変入力を
扱うセッション内だけで行い、グローバルな結果キャッシュは使いません。

| 設定 | 既定値 | 単位・範囲 |
| --- | ---: | --- |
| `MaxFormulaLength` | 8192 | 数式ごとの UTF-16 コード単位 |
| `MaxAstNodes` | 16384 | 数式ごとの AST ノード数 |
| `MaxSyntaxDepth` | 128 | パーサー・AST の深さ |
| `MaxDependencyDepth` | 256 | 同時に辿るセル依存の深さ |
| `MaxFormulaCells` | 100000 | セッションごとに評価する数式セル数 |
| `MaxCellVisits` | 1000000 | セッションごとのセル読取・範囲訪問回数 |
| `MaxEvaluationSteps` | 2000000 | セッションごとの検証・評価ステップ |
| `MaxStringLength` | 32767 | 一時的な連結を含む、評価する Text 一値の UTF-16 長 |
| `MaxCachedStringCharacters` | 16777216 | 異なるキャッシュセルが保持する Text の UTF-16 長の合計 |

Text の二つの上限は0を許可し、それぞれ空の評価 Text／保持 Text だけを許可します。
負数はセッション生成時に拒否します。surrogate pair は UTF-16 で2単位です。同一セルの再読取や
同じ結果の results 辞書登録は二重計上せず、同じ文字列でも異なるセルなら各セル分を数えます。
保持しない `Evaluate(parsed)` の返却値は累積予算に含めず、連結は結果の確保前に合計長を検査します。
Text の上限診断には数式セル・元の Span・超過した上限名を含め、全文字列は含めません。
呼出し元のデータ・OpenXml スナップショット・プロセス全体のメモリはこの予算の対象外です。
Excel のすべての Unicode 長さ規則との互換保証でもありません。
設定例と保持量の詳細は[使い方ガイド](formulas.ja.md#文字列の資源制限)を参照してください。

## 未対応の機能

| 分類 | 例 |
| --- | --- |
| 一覧以外の関数 | XLOOKUP、CONCAT、TODAY／NOW、財務関数など、表の40関数にないすべての名前。 |
| 配列計算 | 配列定数、旧式配列数式、動的配列・スピル、配列を返す評価。到達した XLSX data table 数式・計算メタデータも拒否します。 |
| 参照文法 | 外部ブック、3D、構造化・テーブル参照、R1C1、暗黙の交差 `@`、スピル `#`、参照の和集合・交差。 |
| 名前・実行 | 式・相対・複数領域の定義名、INDIRECT／OFFSET、LET／LAMBDA、揮発性の実行、UDF／VBA、反復・循環計算。 |
| ロケール・日付 | 翻訳された数式構文、ロケール依存の文字比較、ロケール依存の日付文字列・タイムゾーン付きISO日付セルの変換。数値のシリアル日付は計算器では通常の数値です。 |

CachedValue 描画での定数文字列 HYPERLINK のリンク情報抽出は別機能であり、HYPERLINK は
計算器の対応関数ではありません。条件付き書式・入力規則の式はブックのメタデータとして保持し、
条件付きスタイルの描画のためには計算しません。対応関数であっても、到達する依存先が未対応の
機能を使ったり、資源上限を超えたりすると失敗します。

この一覧は実装済みの範囲で、Excel 実機との互換性認証ではありません。検証対象 SHA と
未実施の範囲は[統合検証](formulas-validation.md)、[レビュー修正の検証](formulas-review-fixes-validation.md)、
[性能](formulas-performance.md)に記録しています。

## 追加関数の限定プロファイル

組込みDataSourceは `ISparseFormulaDataSource` とシート／行／列索引を使います。
既存の `IFormulaDataSource` 実装は変更不要で、上限付き密走査へフォールバックします。
列挙は完全・重複なし・行優先順で、空文字／0／エラーを返す数式と計算メタデータも含めます。
欠落Blankはキャッシュしません。`FormulaSession.GetStatistics()` で実読取り、候補数、
空白一括処理、訪問数、ステップ、保持値数を確認できます。条件範囲は相対位置のカーソル
マージで整合させ、全列配列は確保しません。

Criteriaの数値Text・Boolean・空文字・エラーの詳細は暫定の[Oracle表](formulas-oracle.md)
で管理します。ワイルドカードは `* ? ~`、照合はOrdinalIgnoreCaseです。検索は同じ
ワイルドカード構文を使い、数値と数値Textは区別します。添字の小数は0方向へ切捨てます。
近似検索、INDEXの0添字による配列、多セルのスカラー引数は未対応診断です。

`FormulaEvaluationOptions.DateSystem` の単独既定はExcel1900で、OpenXmlではブックの
Date1904を優先し、呼出し元Optionsは変更しません。タイムゾーンなしISO日付を明示変換し、
時刻小数を保持します。1900系はserial 0を1900/1/0、60を架空の1900/2/29として保持します。
負数・範囲外は#NUM!、ロケール依存の日付文字列は解析しません。月数は0方向へ切捨てます。

TEXTは `0`、`00000`、`0.00`、`#,##0`、`#,##0.00`、`0%`、`0.00%` と引用リテラル、
`yyyy-mm-dd`、`yyyy/mm/dd`、`yyyymmdd`、`yyyy年m月d日`、`yyyy年mm月` 等の限定構文です。
半角英字の大小は無視し、数値区切りは . と ,、丸めは既存DecimalRoundingを使います。
時刻・曜日・月名・和暦・言語コード・色・条件・指数・分数・会計書式は未対応診断です。
UTF-16互換性v1を固定し、生成前の長さ見積もりと既存の累積Text予算を適用します。

完全一致検索はセッション内で評価済みの先頭部分だけを索引化します。異なるキーでも
既に索引にあれば再走査せず、先頭重複・型・エラー順・遅延評価を保ちます。
保持は16範囲・65536値・Text 131072 UTF-16単位までで、超過時は上限付き逐次検索へ
戻します。呼出し間で列挙カーソルは保持しません。ワイルドカードは評価予算内で
限定した索引を照合してから未走査部分へ進みます。疎範囲索引も連続配列を使い、
行ごとのオブジェクト確保を避けます。

索引の列占有情報で全セルが実在すると確認できた矩形は直接走査します。空白や
メタデータだけのUsedRangeを根拠に走査しません。疎／外部カーソルの順序・重複・
範囲検査を維持し、カーソル進行とそのセル読取りは1回として予算へ計上します。
集計・条件照合の作業は別に計上します。
