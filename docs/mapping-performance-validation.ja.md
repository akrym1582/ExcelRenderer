# Mapping 性能改善の実装・検証

2026-10-09。[調査と実装計画](mapping-performance-plan.ja.md)に基づく本体変更。

## 実装した範囲

- 値・書式中心の繰り返しを最終行の並びに平坦化し、トップレベルの領域ごとに1回の行数変更で配置する。
  単純配列、明示的ブロック、ネストを同じ方式で扱い、シート全体はクリアしない。
- 繰り返し内のセル数式を、空配列でも元アドレスを示して出力前に拒否する。
  ワークブック／シートスコープの定義名で、参照範囲が繰り返す行帯（マーカーを含む）へ重なるものも拒否する。
- 結合の右端をコピー幅に含め、右端結合が欠落する不具合を修正する。
- 外側の数式・定義名は、下側も含めて既存の参照更新を維持する。
  フッターや別シートからの参照は空・1件・複数件のテストで確認する。

高速配置は、ワークブックにセル数式・定義名がなく、対象シートに結合、条件付き書式、
入力規則、スパークライン、テーブル、画像、印刷範囲、印刷タイトル、コメント、リンク、
リッチテキストがない場合に適用する。それ以外は既存の行操作・範囲コピーを維持する。
この選択は対応可否の判定ではなく、機能を保つための展開方法の選択である。
結合・外側の数式などを含むケースの高速化は今回の完成範囲に含まない。
式で動的に範囲を作る定義名の依存解決は追加していない。

繰り返しの内側の数式・重なる範囲名を非対応にした点は互換性の変更である。
日本語・英語ガイドの初回請求書例も、計算済みの `LineTotal` を入力で渡す形へ変更した。
条件付き書式・入力規則の式に新しい拒否条件は追加せず、既存の範囲コピーを維持する。

## 検証方法

全ソリューションを Rebuild し、StyleCop を含む警告0・エラー0を確認して全テストを実行する。
描画テストは既存レポートに記載された Fontconfig 設定を使用する。
Mapping には数式拒否、両スコープの名前、右端結合、ネスト・空の子配列・複数領域、
親エイリアス、使用範囲の右側の空セルの書式、非表示・アウトライン・改ページ、
下側の数式・名前・印刷設定と別シート参照の回帰テストを追加した。

性能は Release の新規プロセスで測定する。入力準備・出力検証を mapping 時間から除外し、
再読込した全データセルの値・型、各行の書式・行高、全結合アドレスを検証する。
数式モードは新しい制限による拒否と出力が空であることを確認する。
時間・累積割当・ピーク RSS は区別し、ピークには入力準備も含む。
