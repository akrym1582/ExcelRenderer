# Add explicit sheet ranges, drawing-bound trimming, and PDF/Markdown hyperlinks

Explicit A1 selections now replace selected sheets' print areas and clip cells, partially selected merges, images and rotated shapes at their original positions. A shared viewport trims finalized drawing commands per page/canvas without changing pagination, font measurement or scaling, and supplies final PDF/PNG/SVG dimensions and optional schema-1 manifest metadata.

Open XML hyperlink definitions and literal-string HYPERLINK formulas are retained separately from display values. PDF annotations are written to the final imported document after page selection and trimming. Markdown uses shared context-aware escaping, stable cell anchors and explicit lists for empty/range sources. The shared URI policy accepts HTTP(S)/mailto, rejects unsafe targets without disclosing them in diagnostics, and defers warning/Strict evaluation until selected output is known. PNG/SVG and Hyperlinks.None do not evaluate hyperlink diagnostics.

The public additions preserve existing positional constructors and default layout: SelectionOptions.Ranges/MaxRangeCells, RenderRequest.Trim/Hyperlinks, Markdown/PDF options, page/source metadata. Unified render gains range/trim/link flags; legacy PDF/Markdown share the link option. PDF output is opened only after validation and Strict preflight, and identical input/output paths are rejected before reading. Both READMEs and architecture documents describe implemented behavior and limitations. Product dependencies and versions are unchanged.

Validation: locked restore; font SHA256 checks; Release Rebuild with zero warnings/errors; 318 library and 30 CLI tests passing without skips; library and tool pack; local nupkg tool installation; actual PDF/continuous PNG/continuous SVG/Markdown generation with system fonts disabled. Saved PDFs are reopened to assert MediaBox, annotations, Rect, URI, XYZ and final-document page references. Generated XLSX fixtures are saved and read through ExcelReader; PNGs are decoded and SVGs reloaded/rasterized. A separate packaged-output probe checks dimensions, links, raster correspondence and Markdown anchor integrity. All 19 output mutations were detected, including the five new required cases; originals were restored and final tests are green.

See [the detailed validation record](https://github.com/akrym1582/ExcelRenderer/blob/feat/ranges-trim-hyperlinks/docs/ranges-trim-hyperlinks-validation.ja.md) for test names, fixes, evidence, reproduction paths and untested combinations. Samples are generated under TestResults/RangeTrim; they are not tracked as binary repository assets. Excel desktop comparison and Windows/macOS execution were not performed.
