# Core border workbook

`border-conflicts.xlsx` is a Core-owned copy of the deterministic workbook
introduced in PR #99, generated by
`docs/validation/border-resolution/create-fixture.py`.

SHA-256: `a07e159caa4a83a12c38231f70cbf2ca6bdcded9404291ba5244e8f03249a12a`

`BorderResolutionTests` uses its `Double` sheet to verify that saved border
IDs reach the Core shared-edge resolver. The checked-in copy is intentional:
Core's sparse test checkout must not read fixtures from the main test project.
