# Leading blank row/column correction

These follow-ups retain every historical input, PDF and hash. They cover only:

| Contract | Restored source dimensions | Shift in page points |
| --- | --- | --- |
| Full `image-anchor` | Two 51.75pt columns and one 15pt row, at scale 1 | +103.5 X, +15 Y |
| Main/Core `09-cell-border` | One 18pt column and one 18pt row, at scale 0.6 | +10.8 X, +10.8 Y |

`manifest.json` binds each unchanged input and historical PDF to an exact corrected
PDF. The image fixture also binds the old finalized report and the corrected
command fingerprints, page plan and source regions. Other report fields retain
the historical expectations.

`scripts/print_origin_evidence.py` independently checks page count/boxes, character
codes and glyph IDs, text styling, image pixels/dimensions/transforms and painted
geometry. Text, images and ordinary paint move only by the specified source-axis
shift. Ten explicitly identified dotted border strips in the border workbook have
native clipped terminal-dot differences: their dots must remain black 0.3pt squares
with a 0.9pt period, with endpoints within one period of the translated strip.
All other paints retain their exact translated geometry. This narrow difference
is additionally fixed by the exact decoded content/paint and 144/300dpi snapshots.

The main/Core appearance gate compares the corrected references at its unchanged
144/288dpi pixel and geometry checks. The backend gate uses the corrected image
reference for both historical stages, retaining raw/finalized stream preservation,
resource checks and exact current content/pixels. No general raster tolerance is
increased, no output is aligned dynamically, and no reference is regenerated by CI.

Validation:

```sh
python scripts/test_print_origin_evidence.py
python scripts/compare-pdf-backends.py --no-build
python scripts/compare-pdf-backends.py --no-generate --reference B --no-exceptions
python scripts/check-libreoffice-regression.py
```

The first command checks all three bound references and rejects an incorrect
origin shift, missing image, extra ink and missing text. `artifact-hashes.json`
records the retained evidence; update it if this evidence changes.
